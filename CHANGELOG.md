# Changelog

## 0.1.0 — Initial public source release

- USB microphone: 48 kHz mono, 16-bit PCM.
- Front-button audio gate, hold timeout, Claude Space hold, and Codex F8 mode toggle.
- Original display mascots and English/Turkish UI options.
- ESP-IDF 5.4 build, pinned dependencies, and configurable controls.
- Flash tooling with default backup and verification, plus full-flash restore.
- Setup, architecture, privacy, compatibility, and contribution documentation.

This source release follows an internal macOS prototype. Public-release hardware acceptance remains pending; see [compatibility](docs/compatibility.md).
